# 关于

这里是 [FangYuan](https://github.com/Virace/FangYuan) 的演示站点，用来展示当前主题和内容能力。

## 这里主要展示什么

- 当前主题的中文化 demo 内容
- Markdown 扩展、内容指令和媒体嵌入等前端展示能力
- 内容与主题分离、外部 `site/` 输入层，以及评论相关能力的演进方向

## 相关入口

::github{repo="Virace/FangYuan"}

- 主题仓库：[Virace/FangYuan](https://github.com/Virace/FangYuan)
- 相关文章：[内容与主题分离，以及评论接入](/content-theme-separation-and-comments/)
- 文章总览：[归档页](/archive/)

## 当前状态

当前公开仓库主要承担主题源码和 demo 展示，后续正式站点内容会按双仓方案独立维护。评论、反馈和页面统计能力已经预留接口，但是否启用取决于站点配置和后端接入状态。
