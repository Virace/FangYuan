# 一级标题

段落之间使用空行分隔。

第二段。_斜体_、**粗体**，以及 `等宽文本`。无序列表看起来像这样：

- 第一项
- 第二项
- 第三项

请注意，正文内容会从缩进 4 个空格之后开始。

> 引用块
> 可以这样写。
>
> 如果需要，
> 也可以跨越多个段落。

用 3 个连字符表示破折号。用 2 个连字符表示范围（例如“第 12--14 章”）。三个点 ... 会被转换为省略号。
支持 Unicode。☺

## 二级标题

下面是一个有序列表：

1. 第一项
2. 第二项
3. 第三项

再次注意，正文会从左侧第 4 列开始，也就是缩进 4 个字符。下面是一个代码示例：

    # 再强调一次……
    for i in 1 .. 10 { do-something(i) }

如你所见，这里用了 4 个空格缩进。除此之外，你也可以不用缩进，而是改用围栏代码块：

```
define foobar() {
    print "欢迎来到示例世界！";
}
```

这样复制和粘贴会更方便。你也可以额外给围栏代码块标记语言，启用语法高亮：

```python
import time
# 快一点，开始数到十！
for i in range(10):
    # （不过别太快）
    time.sleep(0.5)
    print(i)
```

### 三级标题

下面是一个嵌套列表示例：

1. 先准备这些食材：
   - 胡萝卜
   - 芹菜
   - 扁豆

2. 烧一锅水。

3.  把所有东西都倒进锅里，然后按下面这个流程操作：

        找到木勺
        打开锅盖
        搅拌
        盖上锅盖
        小心地把木勺架在锅柄上
        等 10 分钟
        回到第一步（或者煮好后关火）

    不要碰到木勺，否则它会掉下来。

再看一次，正文总是会和 4 空格缩进对齐，包括上面接在第 3 项后面的那一行。

这里有一个指向[某个网站](http://foo.bar)的链接、一个指向[本地文档](local-doc.html)的链接，以及一个指向[当前文档章节标题](#二级标题)的链接。这里还有一个脚注 [^1]。

[^1]: 这里是脚注内容。

表格可以使用标准 GFM 管道语法，并通过冒号控制各列对齐方式：

| 尺码 | 材质 | 颜色 |
| ---: | :--: | :--- |
|    9 | 皮革 | 棕色 |
|   10 | 麻布 | 原色 |
|   11 | 玻璃 | 透明 |

也可以在单元格里组合 **加粗**、`行内代码` 与较长说明，窄屏下容器会自动提供横向滚动：

| 语法类型 | 写法示例                         | 说明                                                |
| :------- | :------------------------------- | :-------------------------------------------------- |
| 删除线   | `~~已过时内容~~`                 | 渲染为 ~~已过时内容~~，适合标注修订                 |
| 快捷键   | `<kbd>Ctrl</kbd> + <kbd>K</kbd>` | 渲染为 <kbd>Ctrl</kbd> + <kbd>K</kbd>，适合操作指南 |
| 行内代码 | `` `pnpm dev` ``                 | 渲染为 `pnpm dev`，突出命令或标识符                 |
